# QA Fundamentals — Learning Notes

## Test case

A defined scenario with inputs, steps and an expected result. It is useful for repeatable checks and regression testing.

## Exploratory testing

Simultaneous learning, test design and execution. The tester uses a charter and records evidence while adapting to discoveries.

## Severity and priority

- **Severity** describes how strongly a defect affects the product or user.
- **Priority** describes how urgently the team should address it.

## Useful bug report qualities

- Clear, specific summary
- Exact environment and preconditions
- Minimal reproducible steps
- Separate expected and actual results
- Evidence where useful
- Neutral, factual language

## Regression testing

Rechecking important existing functionality after a change to find unintended effects.
