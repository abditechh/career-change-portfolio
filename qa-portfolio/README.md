# Software QA Learning Portfolio

This repository shows what I am learning as I try to move from industrial production into software testing. I am still a beginner, so the work here shows my effort and progress—not professional QA experience.

## Purpose

My aim is to practise understanding expected behaviour, checking software carefully and describing problems clearly enough for another person to reproduce them.

## System under test

My first practice project is a Job Application Tracker built with HTML, CSS, JavaScript, Firebase Authentication and Cloud Firestore.

Main functions:

- User registration, login and logout
- Add, edit and delete job applications
- Search and filter applications
- Track application status
- Export application records as CSV
- Synchronise data between devices

## Skills being practised

- Requirement analysis
- Positive and negative test cases
- Boundary and validation checks
- Authentication and session testing
- CRUD and data-persistence testing
- Responsive and usability testing
- Clear defect reporting
- Regression checklists
