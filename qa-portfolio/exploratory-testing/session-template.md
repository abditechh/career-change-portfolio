# Exploratory Testing Session

## Charter

Explore **[feature]** to discover problems that could prevent **[user]** from completing **[goal]**.

## Time box

30–45 minutes.

## Areas to explore

- Normal user workflow
- Missing or invalid inputs
- Navigation and recovery from errors
- Data persistence after refresh
- Mobile layout and keyboard use
- Privacy and access between accounts

## Test notes

Record actions and observations chronologically.

## Issues found

Link each observation to a full bug report where appropriate.

## Questions and risks

List unclear requirements, untested areas and follow-up ideas.
