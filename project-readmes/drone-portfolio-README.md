## Repository-size warning

The current local folder contains duplicated high-resolution images and very large video files. Before publishing:

1. Keep only the strongest media sample.
2. Compress images for web use.
3. Host large video externally or use an appropriate large-file solution.
4. Add thumbnails rather than committing multiple original videos.
5. Remove duplicate files and operating-system metadata.
